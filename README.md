# Site da UC Projeto Integrador (L.EIC) – 2026/27

Fontes em Markdown do site público da unidade curricular, publicado com GitHub Pages (Jekyll, tema *Just the Docs*).

| Ficheiro | Página |
|---|---|
| `index.md` | Entrada: visão geral, modalidades, calendário, contactos |
| `propostas.md` | Fase 1 – Propostas, candidaturas, alocação de estudantes e tutores |
| `contratos.md` | Contratos de estágio |
| `realizacao.md` | Fase 2 – Realização do projeto |
| `finalizacao.md` | Fase 3 – Entregas e avaliação |
| `entidades.md` | Página para entidades de acolhimento (proponentes) |

Princípio editorial: a **ficha da UC no SIGARRA** é a referência oficial (objetivos, programa, avaliação, fórmula). O site não a repete; acrescenta apenas procedimentos, prazos, formulários e modelos.

## Publicação

Settings → Pages → *Deploy from a branch* → `main` / `(root)`.

Pré-visualização local (opcional): `bundle exec jekyll serve` com um `Gemfile` que inclua `github-pages` e `jekyll-remote-theme`.
